📱 SIM Localisation Management (Java 8)
A Java 8-based application for efficient management of SIM cards, user accounts, and regional data. The project utilizes modern Java features to provide a modular, functional, and scalable system with integrated reporting and analytics capabilities.

🔑 Key Functionalities
👤 User Account Management
Create, update, and manage user accounts with role-based access.

🌐 SIM and Region Management
Register and manage SIM cards and their associated regions for localization tracking.

📊 Reporting and Analytics
Generate insightful reports based on SIM usage, location, and user activity.

🛠️ Technologies Used
Java 8

Lambda Expressions

Functional Interfaces

Streams API

Default Methods

Optional Class

Date & Time API (java.time)

Basic Java collections and OOP principles
